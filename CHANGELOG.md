# Changelog

All notable changes to the CDE Revival Theme plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-21

### Added
- Initial release of CDE Revival Theme
- Classic CDE/Motif color scheme with authentic grey tones
- Beveled 3D UI elements with strong light/dark edges
- Blue and steel accent colors (#627C9C)
- Subdued selection backgrounds
- Complete editor color scheme with retro console colors
- Support for IntelliJ Platform 2023.2+ (builds 232-242)
- Comprehensive UI theming for all JetBrains IDE components:
  - Buttons with gradient backgrounds and beveled borders
  - Menus and toolbars with classic styling
  - Trees, tables, and lists
  - Tool windows with authentic headers
  - Progress bars and scrollbars
  - Search and completion popups
  - Version control elements
  - Welcome screen

### Theme Characteristics
- **No rounded corners**: All UI elements use sharp, square edges (arc: 0)
- **Authentic color palette**: Based on classic Unix workstation aesthetics
- **Light theme**: Designed to match the original CDE look and feel
- **High contrast borders**: Clear separation between UI elements
- **Muted accents**: Subdued colors that don't distract from work
