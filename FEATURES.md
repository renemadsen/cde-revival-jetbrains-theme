# CDE Revival Theme - Features

A comprehensive list of features and capabilities of the CDE Revival Theme.

## Overview

The CDE Revival Theme is a faithful recreation of the Common Desktop Environment (CDE) aesthetic for JetBrains IDEs, bringing the classic Unix workstation look to modern development tools.

## Visual Features

### Classic Color Palette ✓

- **Base Greys**: Authentic grey tones (#AEB2C3, #9CA0B1, #C7CBD6)
- **Editor Background**: Light grey (#C7CBD6) for comfortable coding
- **Dark Accents**: Steel grey borders (#5C6574)
- **Blue Selection**: Subdued blue (#627C9C) for selections
- **Muted Colors**: All colors chosen for low eye strain

### Beveled 3D Interface ✓

- **Light Top/Left Borders**: White (#FFFFFF) for highlights
- **Dark Bottom/Right Borders**: Steel grey (#5C6574) for shadows
- **Gradient Backgrounds**: Smooth transitions for depth
- **Pressed States**: Inverted bevel for button feedback
- **Authentic Look**: True to original Motif toolkit

### Sharp, Rectangular Design ✓

- **No Rounded Corners**: All elements use `arc: 0`
- **Clean Lines**: Sharp edges throughout the UI
- **Consistent Geometry**: Rectangle-based design language
- **Classic Appearance**: Matches original CDE windows
